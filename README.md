# 🌬️ Planta de Levitación Aerodinámica

Repositorio asociado al **Trabajo Fin de Grado (TFG)** desarrollado por **Izei Ordorika** en la **Universidad del País Vasco / Euskal Herriko Unibertsitatea (EHU)**, en colaboración con el **Grupo de Investigación en Control Inteligente (GICI)**.

## 🎯 Descripción del proyecto

Este repositorio reúne los códigos, documentos y materiales complementarios utilizados durante el desarrollo del TFG relacionado con el estudio de una **planta de levitación aerodinámica**.

El trabajo se enmarca en el ámbito de la Automática y la Ingeniería de Control, abordando el análisis y estudio de un sistema físico cuya dinámica permite mantener un objeto suspendido mediante un flujo de aire.

El repositorio tiene como finalidad organizar los recursos desarrollados durante el proyecto, facilitar su seguimiento y conservar la documentación técnica asociada.
