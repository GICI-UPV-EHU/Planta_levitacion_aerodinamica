# 📚 Información complementaria

Esta carpeta reúne materiales de apoyo relacionados con el **Trabajo Fin de Grado (TFG) de Izei Ordorika**, dedicado al estudio de una **planta de levitación aerodinámica**.

## 📂 Contenido

Aquí se podrán incorporar, entre otros recursos:

- Documentación técnica de la planta y sus componentes.
- Manuales, hojas de características y referencias bibliográficas.
- Esquemas, imágenes y diagramas de apoyo.
- Resultados o documentos adicionales que complementen la memoria y el código.

## 📝 Organización

Se recomienda utilizar nombres de archivo descriptivos y, cuando resulte útil, crear subcarpetas para agrupar materiales similares.

Los documentos de terceros deberán conservar su referencia de origen y respetar las condiciones de uso correspondientes.
